 QM Thermodynamics Pipeline for ModelSEED (ORCA + xtb)

 Context

 ModelSEED currently derives compound formation energies (ΔGf) and reaction ΔG from group/component-contribution methods, all fit to experimental data — none use
 quantum mechanics:
 - ModelSEED GCM (ModelSEEDDatabase/Biochemistry/Thermodynamics/ModelSEED/*_MolAnalysis.tbl): Jankowski-style group decomposition (WCOOn, PrimOH, …) → ΔGf +
 uncertainty.
 - eQuilibrator (.../eQuilibrator/*.tbl): Component Contribution, per-compound ΔGf + per-reaction ΔG anchored to experimental TECRDB (note the -8.51+/-0.05
 experimental column).
 - dGPredictor (.../dGPredictor/json_files/*.json): ML + group decomposition, dG_mean/dG_uncer per reaction.

 Goal: an automated workflow that computes aqueous Gibbs energies for structures and ΔG for reactions at the quantum level, to get more accurate (and
 extrapolatable) energies than group contribution. First milestone: validate on the 83 central metabolites in
 thermodynamic_calc/central_metabolites_in_opentecr.json (they map to openTECR experimental reactions), benchmarking QM against experimental openTECR + the three
 existing methods.

 Decisions locked in (from user):
 - QM engine: ORCA 6.1.1 (tarball at /nfs/lambda_stor_01/homes/rzhu/orca_6_1_1_linux_x86-64_shared_openmpi418_nodmrg.tar.xz), with xtb (GFN2) for cheap conformer
 screening. Backend kept pluggable.
 - Scope: the 83 openTECR central metabolites.
 - Output: both per-compound aqueous G and per-reaction transformed ΔG'° (pH 7, I=0.1 M, 298 K).
 - Protocol: rigorous (ensemble screen + DFT opt/freq/SMD on lowest conformers), with conformer-count / DFT-level as config knobs to scale down later.

 The science (protocol per molecule)

 1. Microspecies / protonation — trust the JSON pH-7 SMILES/charge (ModelSEED stores pH-7 microspecies); optionally enumerate dominant tautomers (RDKit).
 Implicit solvent is still required (protonation ≠ solvation).
 2. Conformer ensemble — RDKit ETKDG (N≈20–50) → MMFF prune → xtb GFN2 (ALPB water) optimize all → keep lowest 1–3 within an energy window.
 3. DFT (ORCA) — r2SCAN-3c (modern cost/accuracy composite, def2-mTZVPP + D4) geometry opt + analytic/numeric frequencies (quasi-RRHO Gibbs correction) with
 SMD(water) solvation. Optional higher single-point (e.g. wB97X-V/def2-TZVPD) as a config knob.
 4. Assemble G_aq — per conformer G = E(SMD) + G_RRHO(thermal+entropy); Boltzmann-average over conformers → one aqueous standard G per compound. Standard-state
 corrections (1 atm→1 M) applied.
 5. Reaction ΔG — ΔrG = Σ G(products) − Σ G(reactants) (absolute QM reference cancels when atoms balance). Legendre transform to ΔG'° at pH 7 + proton
 bookkeeping, Debye–Hückel for ionic strength I, at T=298 K — matching openTECR/eQuilibrator conventions.

 ▎ Absolute per-compound QM G are internally consistent (not directly comparable to eQuilibrator's ΔGf reference), but reaction ΔG'° is directly comparable to
 ▎ experiment — that is the benchmark axis.

 Deliverables / repo layout (new package under thermodynamic_calc/)

 - setup_orca.sh — unpack tarball to ~/orca_6_1_1, create orca-mpi conda env with OpenMPI 4.1.8, write env-setup snippet (PATH, LD_LIBRARY_PATH, full-path orca
 invocation required for MPI), smoke-test a 1-core + 2-core H2O job.
 - config.py — paths (ORCA bin, xtb, scratch=/tmp), conditions (pH 7, I=0.1, T=298.15), conformer params, DFT level strings, core/parallel layout.
 - structures.py — load the 83 JSON; SMILES→RDKit mol; tautomer/microspecies handling; formula/charge sanity checks vs JSON.
 - conformers.py — ETKDG embed, MMFF prune, xtb optimize (xtb CLI or ASE), energy-window selection.
 - qm_backend.py — abstract backend; XTBBackend, ORCABackend (optimize / frequencies+thermal / SMD single-point → G_aq). Scratch managed on local disk, parsed
 via cclib + targeted regex.
 - thermo.py — per-conformer G assembly, Boltzmann averaging, standard-state corrections.
 - reactions.py — load openTECR reactions among the 83 (dependency: obtain the openTECR/TECRDB reaction table — measured Keq/ΔG'°; source from the openTECR repo
 or eQuilibrator data and cache locally); compute ΔrG and transform to ΔG'°.
 - benchmark.py — QM vs openTECR experimental vs GCM/eQuilibrator/dGPredictor; MAE/RMSE/plots into figures/.
 - pipeline.py (CLI) — orchestrate; parallelize across molecules with joblib/multiprocessing (e.g. ~10 molecules × 8 ORCA cores each on 80 cores).
 - Results cached as JSON per compound (resumable; skip completed).

 Build / verification order

 1. Install ORCA (setup_orca.sh) and pass the H2O smoke test (serial + MPI-parallel).
 2. Smoke pipeline on ~3 easy molecules (water, pyruvate, L-lactate): full ETKDG→xtb→ORCA r2SCAN-3c+SMD path; confirm parse + sane G.
 3. One reaction end-to-end (e.g. lactate dehydrogenase pyruvate↔lactate or a hydrolysis in the set): ΔG'° within a few kJ/mol of openTECR.
 4. Full 83 run; generate the benchmark table/plots; compare QM MAE vs the three GC methods against openTECR.
 5. Document scaling knobs (single-conformer, lower DFT) for future whole-DB extension.
