# Workspace archive

This directory holds superseded workspace material retained for reference. It
is not the supported implementation or a source of current manuscript results;
use `../src/metag` and the evidence index in `../analysis/README.md` instead.

The [2026-10-26 cleanup](2026-10-26-workspace-cleanup/manifest.json) preserves
two outdated handoffs and an old generated dev20 build. The manifest records
original paths and SHA-256 hashes. Dated analysis directories remain at their
original paths because their records and verification tools may depend on those
paths. The dev20 build is historical and must not be used to install MetaG.

The [generated-metadata cleanup](2026-10-26-generated-metadata/manifest.json)
preserves stale dev20 package metadata that was replaced with metadata generated
from the current dev24 project configuration. The evaluated snapshot retains
its own metadata and source identity.
